# 🧱 Roblox Vocab Legends: Web Quest
> **2D Roblox-Style Educational Game: ศึกมหาเวทบล็อกซ์ พิชิตศัพท์เว็บ (10 Questions Strict)**

เกมการศึกษาเรียนรู้ศัพท์การเขียนโปรแกรมและพัฒนาเว็บไซต์ (40 คำศัพท์ 4 หมวดหมู่) ในรูปแบบเกมแอ็กชัน 2D Roblox Blocky สีสันสดใส น่ารัก เหมาะสำหรับเด็กและผู้เรียนทุกคน พร้อมระบบเสียงอ่านออกเสียงภาษาอังกฤษ (Text-to-Speech), ระบบไอเทม Power-Up 5 ชนิดที่ควบคุมด้วยการคลิกบนหน้าจออย่างปลอดภัย (Click-Only Control), ระบบ Boss Battles และการส่งผลคะแนนผู้เรียนไปยัง **Google Sheets API** อัตโนมัติ

## 🎮 ไฮไลท์ฟีเจอร์เด่น (Key Features)

### 1. 🌈 หน้าเข้าสู่เกมสไตล์ Roblox สีสันสดใส (Child-Friendly Login Screen)
* ดีไซน์การ์ด 3D สไตล์บล็อกซ์สีพาสเทลและนีออนสะดุดตา พร้อมแอนิเมชันบล็อกลอยในพื้นหลัง
* ฟอร์มกรอกข้อมูล **รหัสผู้เรียน (Student ID)** และ **ชื่อ-นามสกุล**
* ปุ่ม **START GAME / เข้าสู่เกม** ขนาดใหญ่แบบ 3D Bubbly Press-down เด้งดึ๋งพร้อมเสียงประกอบสุดสนุก

### 2. 📖 ตัวหนังสือโจทย์คำถามขนาดใหญ่ ชัดเจน (Font Size >= 20px)
* ข้อความโจทย์คำถามทุกข้อใช้ขนาดตัวอักษร **20px (ตัวหนาคมชัด)** อ่านง่าย สบายตาบนการ์ดไฮคอนทราสต์
* โจทย์คำถามเป็นแบบ **Scenario-Based Challenges (โจทย์สถานการณ์จำลอง)** เช่น *"ต้องการวางข้อความลิขสิทธิ์ © 2026 ที่ด้านล่างสุดของเว็บ ควรใช้แท็กใด? -> `<footer>`"*

### 3. 🔊 ระบบเสียงประกอบ & เสียงอ่านภาษาอังกฤษ (Text-to-Speech)
* **Roblox Oof Sound:** เสียง "Oof" สไตล์เรโทรเมื่อตอบผิดหรือถูกศัตรูชน
* **Text-to-Speech (TTS):** ออกเสียงคำศัพท์ภาษาอังกฤษที่ถูกต้องทันทีเมื่อตอบถูก เพื่อฝึกสำเนียงและทักษะการฟัง
* **Coin Chime & Fanfare:** เสียงเหรียญทองและเพลงเฉลิมฉลองเมื่อผ่านด่าน

### 4. 🚩 กติกาชัดเจน ด่านละ 10 ข้อเป๊ะ (Strict 10 Questions per Level)
* **จบด่านแน่นอน 10 ข้อ:** มีแถบแสดง `Question X/10` ชัดเจน ไม่มี Infinite Loop
* **👑 Boss Battles:** สู้กับบอสตัวใหญ่ Titan Bug King ในข้อที่ **5** และ **10**
* **⚡ RUSH HOUR:** ใน 3 ข้อสุดท้าย (ข้อ 8, 9, 10) ศัตรูจะเคลื่อนที่เร็วขึ้น 30%!
* **Stage Clear Modal:** สรุปผลคะแนนเหรียญ, เวลาที่ใช้, ความแม่นยำ % และปุ่มส่งคะแนน

### 5. ⚡ ระบบไอเทม 5 ชนิดแบบ CLICK-ONLY CONTROL
*(ไม่มีการผูกปุ่มคีย์บอร์ดใดๆ เพื่อป้องกันการกดลั่นขณะพิมพ์ตอบใน Type Mode)*
1. ⏱️ **Freeze Clock:** หยุดเวลาศัตรูทั้งหมด 5 วินาที
2. 💣 **Blox Nuke:** ระเบิดทำลายล้างศัตรูทั้งหมดบนหน้าจอทันที
3. 💡 **Super Hint:** ตัด 2 ตัวเลือกที่ผิดออกไป หรือเติม 3 อักษรแรกให้
4. 🛡️ **Roblox Shield:** สร้างเกราะคุ้มกันรับการชนได้ 2 ครั้ง
5. ⚡ **2x XP Boost:** คูณคะแนนเหรียญ 2 เท่า เป็นเวลา 10 วินาที

## 📚 รายชื่อ 40 คำศัพท์และสถานการณ์จำลอง (4 หมวดหมู่)

### หมวดที่ 1: HTML & Structural Tags
1. `<html>` - โครงสร้างรากฐานครอบส่วนประกอบทั้งหมดของเว็บเพจ
2. `<head>` - ส่วนหัวใช้เก็บ Meta Data ชื่อหน้าเว็บ และลิงก์เชื่อมโยง
3. `<body>` - ส่วนแสดงผลหลักที่รวมข้อความ รูปภาพ และปุ่มกด
4. `<header>` - ส่วนหัวของหน้าเว็บ สำหรับใส่โลโก้หรือเมนูหลัก
5. `<footer>` - ส่วนท้ายของหน้าเว็บ สำหรับใส่ลิขสิทธิ์และช่องทางติดต่อ
6. `<h1>` - แท็กข้อความพาดหัวขนาดใหญ่ที่สุด
7. `<p>` - แท็กสำหรับจัดกลุ่มข้อความย่อหน้า (Paragraph)
8. `<a>` - แท็กสร้างการเชื่อมโยงมิติ (Hyperlink) ไปยังหน้าอื่น
9. `<img>` - แท็กสำหรับดึงไฟล์รูปภาพมาแสดงผล
10. `<br>` - แท็กสั่งขึ้นบรรทัดใหม่โดยไม่ต้องเปิดย่อหน้าใหม่

### หมวดที่ 2: CSS & Styling Attributes
11. `color` - คำสั่งกำหนดสีของข้อความและอักษร
12. `background-color` - คำสั่งกำหนดสีพื้นหลังขององค์ประกอบ
13. `font-size` - คำสั่งกำหนดขนาดความใหญ่ของข้อความ
14. `margin` - ระยะเว้นว่างภายนอกเส้นขอบองค์ประกอบ
15. `padding` - ระยะเว้นว่างภายในเส้นขอบองค์ประกอบ
16. `border` - เส้นขอบรอบองค์ประกอบ กำหนดความหนาและสีได้
17. `display` - กำหนดรูปแบบการแสดงผลบล็อก เช่น block, inline, flex
18. `flex` - ระบบจัดวางองค์ประกอบให้ยืดหยุ่น
19. `width` - คำสั่งกำหนดความกว้างขององค์ประกอบ
20. `height` - คำสั่งกำหนดความสูงขององค์ประกอบ

### หมวดที่ 3: JavaScript & Logic
21. `let / const` - คำสั่งสำหรับประกาศสร้างตัวแปรเพื่อเก็บข้อมูล
22. `function` - ชุดคำสั่งที่ทำงานร่วมกันเมื่อถูกเรียกใช้
23. `if...else` - โครงสร้างตรรกะตัดสินใจแบบมีเงื่อนไข
24. `addEventListener` - ดักฟังการกระทำของผู้ใช้ เช่น การคลิกหรือพิมพ์
25. `console.log()` - คำสั่งแสดงผลข้อมูลบนคอนโซลเพื่อตรวจสอบ Bug
26. `alert()` - สั่งให้หน้าจอเด้งป็อปอัปแจ้งเตือน
27. `Array` - ตัวแปรประเภทรายการเก็บชุดข้อมูลหลายตัว
28. `Loop (for/while)` - คำสั่งสั่งให้ชุดโค้ดทำงานซ้ำๆ
29. `document.getElementById()` - คำสั่งค้นหาองค์ประกอบผ่าน ID
30. `return` - ส่งคืนค่าผลลัพธ์กลับออกไปจากฟังก์ชัน

### หมวดที่ 4: Server, Database & Deploy
31. `npm` - เครื่องมือจัดการแพ็กเกจของ Node.js
32. `git push` - คำสั่งส่งโค้ดขึ้นไปเก็บไว้บนคลาวด์/เซิร์ฟเวอร์
33. `API` - ตัวกลางเชื่อมต่อระหว่างสองระบบ
34. `JSON` - รูปแบบรับส่งข้อมูลระหว่าง Client และ Server
35. `HTTP Status 200` - รหัสตอบกลับบอกว่าส่งข้อมูลสำเร็จ
36. `HTTP Status 404` - รหัสแจ้งเตือนไม่พบหน้าเว็บหรือไฟล์
37. `PORT` - ช่องทางเข้าออกดิจิทัลบนเซิร์ฟเวอร์ (เช่น Port 80, 443)
38. `Environment Variable` - ตัวแปรใช้เก็บค่าความลับ เช่น API Key
39. `Node.js` - สภาพแวดล้อมรันภาษา JavaScript ฝั่ง Server
40. `Vercel` - แพลตฟอร์มฝากและเผยแพร่เว็บเพจขึ้นออนไลน์

## 📊 โค้ด Google Apps Script สำหรับบันทึกคะแนนลง Google Sheet

```javascript
function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var data = JSON.parse(e.postData.contents);
    
    if (sheet.getLastRow() === 0) {
      sheet.appendRow(["Timestamp", "Student ID", "Student Name", "Category", "Score", "Time Used", "Accuracy"]);
    }
    
    sheet.appendRow([
      new Date(),
      data.studentId,
      data.studentName,
      data.category,
      data.score,
      data.timeUsed,
      data.accuracy + "%"
    ]);
    return ContentService.createTextOutput(JSON.stringify({"result": "success"})).setMimeType(ContentService.MimeType.JSON);
  } catch(err) {
    return ContentService.createTextOutput(JSON.stringify({"result": "error", "error": err.toString()})).setMimeType(ContentService.MimeType.JSON);
  }
}
```
