## ✨ ไฮไลท์ฟีเจอร์เด่น (Key Features)

### 1. 📂 5 หมวดหมู่คำศัพท์ธุรกิจดิจิทัล (50+ คำศัพท์คัดสรร)
* 📈 **E-Commerce & Digital Marketing**: Conversion Rate, SEO, CTR, CAC, LTV, Omnichannel, Retargeting, A/B Testing, Dropshipping, Churn Rate
* 💳 **FinTech & Payments**: Payment Gateway, Blockchain, Smart Contract, KYC, P2P Lending, Digital Wallet, DeFi, Tokenomics, Neobank
* 🤖 **Data & AI Analytics**: Big Data, Machine Learning, Predictive Analytics, Business Intelligence, Cloud Computing, NLP, Data Mining, Generative AI
* 🚀 **Startup & Strategy**: MVP, Scalability, Pivot, Bootstrapping, Pitch Deck, Monetization, Digital Disruption, Venture Capital, Product-Market Fit, Unicorn
* 🔒 **Cybersecurity & Cloud**: 2FA, Phishing, Encryption, SaaS, PDPA, Zero Trust, Penetration Testing, Firewall

---

### 2. 🎯 5 โหมดการเรียนรู้และเกมสุดมันส์
* ⚡ **Speed Quiz**: ควิซจับเวลา 15 วินาที พร้อมระบบ Streak Multiplier, ตัวช่วย 50:50, เพิ่มเวลา และการอธิบายความหมายอย่างละเอียด
* 🎴 **Memory Match**: เกมเปิดการ์ด 3D จับคู่คำศัพท์ภาษาอังกฤษกับความหมายภาษาไทย พร้อมตัวนับสเต็ปและเวลา
* 🧩 **Word Scramble**: เกมถอดรหัสคำศัพท์ เรียงตัวอักษรภาษาอังกฤษที่สลับตำแหน่งให้ถูกต้อง พร้อมคำใบ้
* 📖 **Flashcards**: แฟลชการ์ด 3 มิติ พร้อมระบบเสียงอ่าน Native English (Web Speech API) และประโยคตัวอย่างการใช้งานจริง
* 📚 **Vocab Glossary**: พจนานุกรมคำศัพท์ธุรกิจดิจิทัล ค้นหาคำศัพท์ได้แบบเรียลไทม์ พร้อมกดฟังเสียงได้ทุกคำ

---

### 3. 🏆 ระบบ Gamification & Sound
* ⭐ **XP & Level System**: อัปเลเวลตั้งแต่ *Novice* จนถึง *Unicorn Founder*
* 🔊 **Web Audio Synthesizer**: ระบบสังเคราะห์เสียงเอฟเฟกต์แบบ Real-time ไม่ต้องพึ่งพาไฟล์เสียงภายนอก
* 🎉 **Confetti Celebration**: แอนิเมชันพลุกระดาษเมื่อทำภารกิจสำเร็จ

## 🚀 วิธีเปิดใช้งานโปรเจกต์ (Getting Started)

โปรเจกต์นี้เขียนด้วย **Pure Vanilla Web Technologies (HTML5, CSS3, JavaScript)** ไม่จำเป็นต้องติดตั้ง Node.js หรือ build process:

1. โคลน Repository นี้:
   ```bash
   git clone https://github.com/s6902042856062-cmd/digital-business-vocab-game.git
   cd digital-business-vocab-game
   ```
2. เปิดไฟล์ `index.html` บนเว็บบราวเซอร์ได้ทันที!
   ```bash
   open index.html
   ```

---

## 🌐 การเปิดใช้งาน GitHub Pages (Free Hosting)

1. ไปที่แท็บ **Settings** ของ Repository บน GitHub
2. ไปที่เมนู **Pages** (แถบด้านซ้าย)
3. ภายใต้ **Build and deployment > Source** ให้เลือก **Deploy from a branch**
4. เลือก Branch: `main` และ Folder: `/ (root)` แล้วกด **Save**
5. รอประมาณ 1-2 นาที คุณจะได้ลิงก์เว็บไซต์ออนไลน์พร้อมแชร์ให้ทุกคนเล่นได้ทันที!
